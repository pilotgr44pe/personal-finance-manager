# Moneta

A small, local-first personal finance manager for manually tracking purchases, bill payments, subscriptions, and income.

## Run it

Open `index.html` in a modern browser. No install, account, server, or build step is required.

## What it does

- Records income, expenses, bills, and subscriptions with dates, categories, and optional notes.
- Records how each entry was paid, including cash, QR payment, cards, bank transfer, and e-wallet.
- Attaches one image or PDF receipt (up to 10 MB) to a transaction, with an in-app preview and download option. Receipt files are stored locally in browser storage and are not included in the JSON backup.
- Summarizes spending, income, and net balance for a selected month.
- Formats amounts in a selectable currency.
- Includes light, dark, ocean, lavender, and sunset appearance themes.
- Tracks recurring bills and subscriptions, upcoming due dates, and estimated monthly costs. Marking one paid records a transaction and advances its next due date.
- Filters transactions by text, type, category, and month.
- Exports a JSON backup from the download button.
- Stores data in this browser on this device; it is not sent to a server. Clearing browser storage removes the data, so export backups if you need to keep them.

The app is designed to work without connecting to a financial institution. Bank synchronization is not included.
